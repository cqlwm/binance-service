## 目标

移除 `ChromeConfig.bin_path` 和 `ChromeConfig.user_data_dir` 两个字段，让 Playwright 回退到捆绑的 Chromium；同步清理所有引用点与文档。

依据：
- `bin_path` 仅被 `_playwright.py:42` 的 `executable_path=` 使用，移除后 `chromium.launch()` 自动用捆绑 Chromium
- `user_data_dir` 全代码库零业务引用（仅配置定义+解析+文档），是纯占位字段
- `save-storage` 走 CDP `connect_over_cdp(debug_url)`，不依赖这两个字段（已确认 `storage_state.py:84`）
- `_parse_chrome` 不校验未知字段（`_require_str` 逐字段取），旧 config 残留字段会被静默忽略，无向后兼容风险

## 风险评估

- **浏览器引擎切换风险（中）：** 捆绑 Chromium 与本机 Chrome 在版本/codec 上可能有差异。但项目操作的是 Binance 网页（标准 HTML/CSS/JS，无视频），Chromium 完全胜任。e2e 测试需登录态，无法在本次环境跑，需用户后续实际验证
- **save-storage 用户体验（低）：** 移除 `user_data_dir` 后，用户手动启动 Chrome 时少了一个路径参照。通过 README 补充说明缓解
- **向后兼容（无风险）：** 旧 config 残留字段被静默忽略，不会报错
