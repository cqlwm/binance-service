## 目标

移除 `BinanceService.__init__` 中从未被任何调用方实际传入的 `browser: Browser | None = None` 形参，并清理由此产生的死逻辑 `_owns_browser`。

依据：`cli.py` 3 处 + `tests/test_e2e.py` 1 处调用均只传 `app_config`；`browser` 形参自 `a8c0ba3 统一cli入口` 起就存在但从未启用。移除后 `browser is None` 恒为 True，`_owns_browser` 恒为 True，属死代码。

## 改动范围：仅 `binance_service/service.py`

### 1. `__init__` 简化

```python
# 改前
def __init__(self, app_config: AppConfig, browser: Browser | None = None) -> None:
    self._app_config = app_config
    self._browser = browser
    self._owns_browser = browser is None
    self._cm: contextlib.AbstractContextManager[Browser] | None = None

# 改后
def __init__(self, app_config: AppConfig) -> None:
    self._app_config = app_config
    self._browser: Browser | None = None
    self._cm: contextlib.AbstractContextManager[Browser] | None = None
```

### 2. `open()` 删除死赋值

```python
# 改前
def open(self) -> None:
    if self._browser is not None:
        return
    self._owns_browser = True          # <- 删除此行
    cm = connect_browser(self._app_config)
    self._browser = cm.__enter__()
    self._cm = cm

# 改后（仅去掉 self._owns_browser = True 那一行）
```

### 3. `close()` 简化永真条件

```python
# 改前
if self._owns_browser and self._cm is not None:
    self._cm.__exit__(None, None, None)

# 改后
if self._cm is not None:
    self._cm.__exit__(None, None, None)
```

### 不变部分

- `from playwright.sync_api import Browser` 保留（类型注解仍需）
- `_browser_instance` property、`__enter__`/`__exit__`、`create_post`/`create_postx`/`symbol_screenshot` 全部不动
- `cli.py`、`tests/test_e2e.py` 无需改动（零调用方传入 browser）
- `build/lib/service.py` 为构建产物，不手动改

## 风险评估

- 风险极低：形参无调用方使用，移除是纯向后无影响的重构
- 死逻辑 `_owns_browser` 同步移除后，`close()` 行为在「self 拥有 browser」这一唯一现存路径下完全等价
