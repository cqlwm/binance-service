## 需求回顾

在 `binance_service/screenshot.py:117-120` 的 TODO：打开币安图表页时，在 `page.goto` 之后、`set_viewport_size` 之前，阻塞等待 K 线接口 `https://www.binance.com/fapi/v1/continuousKlines` 返回 200（忽略 query 参数），确认图表数据真正加载成功后再继续。

已与用户确认的设计决策：
1. **callback 形态**：调用方（screenshot.py）提供阻塞函数，URL 匹配规则写在调用方，`get_or_create_page` 不感知业务 URL
2. **失败处理**：超时抛 `PlaywrightTimeout`，复用现有 `except PlaywrightTimeout` 落盘快照（`_dump_debug_snapshot`）；返回非 200 由谓词 `r.ok` 过滤，等价于未命中，最终走超时路径
3. **复用 tab 分支**（方案 A）：复用已存在 tab 时跳过 callback（tab 已稳定，K 线请求早已过去无需再等）；只在"新开 tab"分支生效
4. **Playwright 同步 API 约束**：`page.expect_response` 谓词只看 `with` 块启动**之后**到达的响应，`goto` 必须在 `with` 块**内部**执行。因此 callback 签名为 `callback(page, navigate)`，callback 内部用 `expect_response` 包裹 `navigate()`

## 技术要点

- Playwright Python 同步 API：`page.expect_response(predicate, timeout=...)` 是 context manager，predicate 形如 `Callable[[Response], bool]`
- `Response.url` 包含 query string，用 `str.startswith(...)` 即可忽略参数
- `Response.ok` 为 True 表示 2xx，谓词用 `r.url.startswith(...) and r.ok`
- 超时类型 `playwright.sync_api.TimeoutError`（已在 screenshot.py 导入为 `PlaywrightTimeout`）

## 实现步骤

### 1. 修改 `binance_service/_playwright.py` — `get_or_create_page` 增加 callback 参数

```python
from collections.abc import Callable

NavigateFn = Callable[[], None]


def get_or_create_page(
    browser: Browser,
    target_url: str,
    timeout: int | None = None,
    callback: Callable[[Page, NavigateFn], None] | None = None,
) -> Page:
    """Find an existing tab with the target URL, or open a new one.

    当复用已存在的 tab 时跳过 callback（tab 已稳定）；
    仅在新开 tab 时调用 callback，由调用方负责在 callback 内部
    用 expect_response 等待特定接口返回 200 后再完成导航。
    """
    for context in browser.contexts:
        for page in context.pages:
            if page.url == target_url:
                logger.info("Reusing existing tab: %s", page.url)
                return page

    context = browser.contexts[0] if browser.contexts else browser.new_context()
    page = context.new_page()

    def navigate() -> None:
        page.goto(target_url, wait_until="domcontentloaded", timeout=timeout)

    if callback is None:
        navigate()
    else:
        callback(page, navigate)

    logger.info("Opened new tab: %s", page.url)
    return page
```

要点：
- `callback` 默认 `None`，**完全向后兼容**——`poster.py:179` 和未来其它调用方无需改动
- 用 `NavigateFn = Callable[[], None]` TypeAlias 提升可读性（遵循 AGENTS.md 第四节第 5 条）
- `navigate()` 闭包捕获 `page`/`target_url`/`timeout`，调用方只管"何时触发"

### 2. 修改 `binance_service/screenshot.py` — 实现 callback 并传入

在 `symbol_screenshot` 内、调用 `get_or_create_page` 之前定义 callback，并替换 TODO 注释：

```python
def _wait_klines_ok(page: Page, navigate: Callable[[], None]) -> None:
    """阻塞等待 continuousKlines 接口返回 2xx，再完成导航。

    币安图表页加载时发出 continuousKlines 请求，确认其返回 200 才表示
    K 线数据真正加载成功。忽略 query 参数，仅匹配 URL 前缀。

    谓词只看 with 块启动后的响应，故 goto 必须在块内执行。
    """
    with page.expect_response(
        lambda r: r.url.startswith("https://www.binance.com/fapi/v1/continuousKlines") and r.ok,
        timeout=config.goto_timeout_ms,
    ):
        navigate()
```
